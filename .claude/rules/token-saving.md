# 토큰 절약 가이드

## 핵심 규칙 5가지

1. 이미 읽은 파일은 다시 읽지 않는다.
2. 도구 호출은 가능한 한 병렬로 실행한다.
3. 20줄 이상 분석은 서브에이전트에 위임한다.
4. 사용자가 이미 설명한 내용은 반복하지 않는다.
5. `@`로 500줄 초과 파일 전체 참조 금지 (필요한 구간·심볼만 지정).

## `@` 파일 참조 가이드

| 파일 크기 | 권장 방법 |
|-----------|-----------|
| 500줄 이하 | 전체 참조 가능 |
| 500 ~ 2,000줄 | 필요한 구간·심볼만 지정 |
| 2,000줄 이상 | 함수·클래스 단위로 분리해서 참조 |

## 컨텍스트 압축 타이밍

- 자동 압축은 95% 시점 — 이미 품질 저하 상태
- **60% 시점에 수동 `/compact`** 실행
- 예시: `/compact 실행해줘. 현재 구현 중인 X 기능과 발생한 에러는 보존해줘.`

## 셸 명령어 출력 주의

- 커밋 200개짜리 `git log` → `--since` 또는 `-n 20` 범위 제한
- verbose 테스트 결과 → 모듈 단위로 분할
- 빌드 경고 가득한 로그 → 필요 시 `head`/`tail`로 상한선

## MCP 서버 관리

- `/mcp`로 연결된 서버 확인
- 안 쓰는 서버 즉시 끊기
- 글로벌: 모든 프로젝트에서 항상 쓰는 것만
